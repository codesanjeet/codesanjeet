## 💻 Featured Projects

### 🎓 EduKiteum: Multi-Tenant School Management SaaS

A multi-tenant platform for managing students, attendance, fees, staff, exams, and day-to-day institutional workflows.

- Tenant-isolated data model with role-based access control (RBAC)
- Secure JWT authentication and permission-aware API design
- Async data layer with SQLAlchemy and PostgreSQL, with caching for hot paths
- Containerized with Docker for consistent local and production environments

**Backend:** Python, FastAPI, PostgreSQL, SQLAlchemy, Pydantic, Redis/Valkey
**Frontend:** TypeScript, React, Next.js
**DevOps:** Docker, Linux

> Source code is maintained in a private repository.

---

### 🤖 AgentKiteum: AI Business Agent (RAG)

A multi-tenant AI chatbot that answers customer questions and recommends products and services using each business's own knowledge base.

- End-to-end RAG pipeline: document ingestion, chunking, embeddings, vector search, retrieval, and response generation
- Per-tenant knowledge isolation so each business only retrieves its own data
- pgvector similarity search inside PostgreSQL, with no separate vector database to operate
- Containerized with Docker

**Backend:** Python, FastAPI, PostgreSQL, SQLAlchemy, pgvector, Redis/Valkey
**AI:** RAG, Embeddings, Vector Search, LLM APIs
**Frontend:** TypeScript, React, Next.js
**DevOps:** Docker

> Source code is maintained in a private repository.
